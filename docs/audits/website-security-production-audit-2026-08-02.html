Critical

AW-001 · Global service-role cleanup endpoint

The deployed handler reads but does not validate Authorization and deletes all teams' expired trash through an RLS-bypassing client. It is dormant only because the service-role environment variable is currently missing.

Fix: deploy verified machine auth and a bounded maintenance operation before adding the key.

High

AW-002 · Admin can seize or destroy ownership

Application RBAC and live team_members policies let admins assign owner, demote/delete an owner, or leave a team with no owner.

Fix: owner-only transactional transfer plus a database last-owner invariant.

High

AW-003 · Cron handlers are redirected to login

The session proxy intercepts Vercel's bearer-authenticated, cookieless cron requests before route-level CRON_SECRET validation.

Fix: verify an explicit machine boundary in the proxy/matcher.

High

AW-004 · Migration ledger drift

Production records 55 migrations, local has 61, several timestamps differ, and three applied historical files were edited.

Fix: backup, map exact SQL/hashes, restore immutable history, then use forward-only migrations.

High

AW-005 · Cross-team attendance relationships

The live policy does not require the attendance member and event to belong to the same team.

Fix: enforce tenant equality in policy/constraints after migration reconciliation.

High

AW-006 · Deployed song-import SSRF

Any signed-in member can make the deployed server fetch an arbitrary URL with no private-IP check, redirect validation, timeout, or size limit.

Fix: deploy the local allowlisted, DNS-checked, bounded fetcher.

High

AW-007 · Authenticated content remains in the service-worker cache

The deployed worker precaches dashboard/teams and caches most successful page GETs without user partitioning or logout purge.

Fix: cache public assets only and delete the legacy cache.

High

AW-008 · Unseed deletes matching user songs

Unseed identifies rows by title, so a user-authored song sharing a seed title is moved to trash.

Fix: record seed provenance or inserted IDs.

High

AW-009 · Release gates are not active

CI/monitor workflows are untracked, production smoke fails, and the local prebuild requires three server variables not configured in Vercel Production.

Fix: review and commit gates, configure secrets in the approved store, and require preview smoke.

Medium

AW-010 · Join request can ask for owner

The live insert policy constrains only profile identity while approval copies requested_role into team_members.

Fix: constrain role/status/reviewer fields and transact approval.

Medium

AW-011 · Child rows can cross team boundaries

setlist_songs validates the destination setlist but not the referenced song/member team; related tables show the same independent-FK pattern.

Fix: tenant-aware constraints/RPCs and per-reference server validation.

Medium

AW-012 · Non-transactional destructive and bulk writes

Deletes ignore intermediate errors; the two-pass reorder can strand +10000 values; bulk arrays are unbounded and race-prone.

Fix: bounded schemas and transactional RPCs with fault-injection tests.

Medium

AW-013 · Incomplete resource and distributed rate limits

Content-Length can be omitted, Spotify calls lack bounds/caching, backfill is N+1, and production lacks Upstash configuration.

Fix: byte/item/time bounds, token caching, batching, and required shared limits.

Medium

AW-014 · Demo E2E misses real authorization

The green forced-demo suite bypasses Supabase auth, RLS, multi-user ownership, machine auth, and migration upgrade behavior.

Fix: isolated real-auth/RLS and production-like integration suites.

Medium

AW-015 · Accessibility gaps

Custom modals lack complete focus/keyboard semantics; some controls are unnamed or 24px; deployed production disables zoom.

Fix: shared accessible dialog/controls and keyboard, axe, reflow, and zoom tests.

Medium

AW-016 · Missing production CSP

Production has no CSP. Local adds one but still permits unsafe-inline scripts.

Fix: deploy baseline headers, then move to nonces/hashes.

Low

AW-017 · Long-lived slide-background bearer URLs

Broad image input is stored in practice-files and represented by a one-year signed URL; server settings have no strict shape.

Fix: dedicated media storage, exact bounds, object paths, and short-lived resolution.

Low

AW-018 · Deployment/documentation drift

Render configuration, README advisory text, historical migrations, and the dirty release packet no longer describe one canonical shippable state.

Fix: choose one deployment path and consolidate reviewed release changes.
