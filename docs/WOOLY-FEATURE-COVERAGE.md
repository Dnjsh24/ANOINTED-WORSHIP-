## Verified limitations

- Setup invitation addresses, timezone and service-day preferences are not persisted by the current team-creation action. Team creation success opens Home.
- Profile preferences other than the implemented save fields remain unsaved. Sync is informational; it does not synchronize the website with a separate desktop app.
- Messages Forward/Pin are status-only controls. Reordering and saving templates require checking the saved result; closing a dialog alone does not prove success.
- Worship Remote requires an approved team account and an online compatible Windows Presenter session. No desktop changes are included.
- Missing targets fall back to text. Record-specific guides require the user to open or choose their own record.
- Unsupported questions offer support. Public help, permission checks and unpublished/private reply separation remain in place.
